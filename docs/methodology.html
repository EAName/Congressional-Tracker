Primary sources

House roll calls
U.S. House Clerk electronic voting system (EVS) XML published at clerk.house.gov. Member positions are Aye / No / Present / Not Voting, joined to Bioguide IDs.
Senate roll calls
Senate Legislative Information System (LIS) XML at senate.gov. LIS member IDs are mapped to Bioguide IDs via the national congress-legislators roster.
Delegation roster
unitedstates/congress-legislators. Virginia seats are versioned by term so mid-Congress changes (for example a special election) appear with correct dates.
District map
These pages use map version 2026 (proposed redistricting lean for Target Four). Source lean table: project config/districts.yaml.

How impact tags work

Votes are tagged for small-business relevance by deterministic rules (keyword and bill-area matches). Human reviewers can promote or override. Model-only guesses never appear on this site or the public scorecard.

What does not appear on district pages

Narrative vote cards require a human plain-language summary under 25 words. We never substitute the parliamentary vote question.

Procedural, cloture, nomination, suspension, and motion-to-recommit categories stay off district briefs; they remain in the audit sheet for internal review. A Nay on procedure is not treated as a policy position.

How to read the scorecard

Each cell is Yea count / Nay count for that member on votes carrying the column’s impact tag. Green means mostly Yea; red mostly Nay; amber split; dash means no tagged votes yet. Counts refresh when this site is rebuilt from the warehouse.
